# Ecuador Nature Expeditions - Back Office

## ¿Qué es?
Sistema de gestión back-office para Ecuador Nature Expeditions. Reemplaza workflows manuales en Excel con software profesional.

## Usuarios
- Sandra Jitala (operadora)
- Administradores de ENE
- Coordinadores de expediciones

## Datos principales
- Expediciones/tours
- Pasajeros y documentación (pasaportes, visas)
- Hoteles (169 hoteles con fotos)
- Itinerarios personalizados
- Reportes y estadísticas

## Tech stack
- React (Lovable frontend)
- Supabase (database)
- n8n (workflows)
- Claude (extracción de datos)

## Tono
Profesional, confiable, facilitador. Que ENE trabaje eficientemente.
