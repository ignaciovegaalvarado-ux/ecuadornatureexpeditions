# Design System - Ecuador Nature Expeditions

## Colores
- **Primary Green**: #2D5016 (naturaleza)
- **Accent Orange**: #E67E22 (aventura)
- **Success**: #27AE60
- **Warning**: #F39C12
- **Error**: #E74C3C

## Tipografía
- Headings: Inter Bold (700)
- Body: Inter Regular (400)
- Monospace: Fira Code

## Tono de diseño
Aventurero pero profesional. Limpio, sin clutter, colores naturales.

## Componentes clave
- Tarjetas para expediciones
- Tablas para pasajeros
- Formularios de documentos
- Dashboards de reportes

## Responsive
- Desktop: 1920px
- Tablet: 768px (usado en campo)
- Mobile: 375px
